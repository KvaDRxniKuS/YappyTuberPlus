# Быстрый запуск

Один файл, который сам скачивает крайние обновления, ставит зависимости и открывает
редактор. Ничего вводить в консоль не нужно.

## Windows

1. Скачайте папку проекта (или только `start-yappytuber.bat`) — например, кнопкой
   **Code → Download ZIP** на GitHub, затем распакуйте.
2. Двойной клик по **`start-yappytuber.bat`**.

Что произойдёт при первом запуске:

1. Проверка Git и Node.js 20+. Если их нет — предложит установить через `winget`
   (Git и Node.js LTS), иначе покажет ссылки для ручной установки.
2. Клонирование ветки с последними изменениями в папку `YappyTuberPlus` рядом с файлом.
3. `npm ci` — установка зависимостей.
4. Сборка WASM-ядра, если установлен Rust с target `wasm32-unknown-unknown`; иначе
   используется уже собранный `public/rig_core.wasm`, и об этом будет строка в окне.
5. Запуск Vite и открытие `http://localhost:5173/` в браузере.
6. Отдельное свёрнутое окно `YappyTuberPlus OBS bridge` — мост для источника браузера
   в OBS (можно отключить флагом `--no-bridge`).

При следующих запусках шаг 1 и клонирование пропускаются: файл просто подтягивает
обновления, ставит новые зависимости при необходимости и запускает редактор.

Остановка — `Ctrl+C` в окне консоли или закрытие окна.

### Параметры

Параметры передаются в ярлыке или из командной строки:

```bat
start-yappytuber.bat --no-open      :: не открывать браузер
start-yappytuber.bat --no-bridge    :: без моста для OBS
start-yappytuber.bat --no-serve     :: только обновить и собрать
start-yappytuber.bat --tauri        :: нативное окно Tauri вместо браузера
start-yappytuber.bat --port 5199    :: другой порт
start-yappytuber.bat --dir D:\Rig   :: папка проекта
start-yappytuber.bat --branch main  :: другая ветка
```

При `--tauri` Vite поднимает сам Tauri, поэтому `--port` в этом режиме игнорируется.

## Linux / macOS

```bash
chmod +x start-yappytuber.sh
./start-yappytuber.sh
```

Параметры те же (`--no-open`, `--no-bridge`, `--no-serve`, `--tauri`, `--port`,
`--branch`, `--dir`). Браузер открывается через `xdg-open`, `open` или `cmd.exe`.

## Что делает автообновление

- `git fetch` и выбор ветки: берётся та, где последний коммит новее — сессионная
  ветка разработки или `main`. Поэтому файл продолжит работать и после слияния
  ветки в `main`.
- Если в папке остались локальные изменения, они сохраняются в `git stash`
  (`yappytuber auto-backup`) — ничего не теряется молча.
- Если ветка разошлась с удалённой, выполняется `reset --hard origin/<ветка>`;
  прежнее состояние доступно через `git reflog` и `git stash list`.
- `node_modules` переустанавливаются только когда их нет; иначе выполняется
  `npm install`, чтобы подхватить новые зависимости.

Требования: Git и Node.js 20+. Rust нужен только для пересборки `rig_core.wasm`;
без Rust используется закоммиченный артефакт. Нативная Tauri-сборка (`--tauri`)
дополнительно требует Rust, MSVC Build Tools и WebView2.

## Если репозиторий приватный

`git clone` и `git fetch` могут один раз попросить вход в GitHub — откроется окно
Git Credential Manager, войдите через браузер и повторите запуск. После этого вход
запоминается, и обновления идут молча.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| «не найден git» / «не найден Node.js» | согласиться на установку через winget или поставить вручную и запустить файл снова |
| Просит логин GitHub | войти один раз в окне Git Credential Manager |
| «не удалось склонировать» | проверить доступ к GitHub и права на репозиторий, затем запустить снова |
| Окно закрылось мгновенно | запустить `start-yappytuber.bat` из `cmd`, чтобы увидеть текст ошибки |
| Порт занят | `--port 5199` |
| Браузер не открылся | открыть `http://localhost:5173/` вручную |
| Нужен чистый старт | удалить `node_modules` и запустить файл снова |
