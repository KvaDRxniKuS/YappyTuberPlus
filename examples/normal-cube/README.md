# Кубик с картой нормалей — тестовый пример

Готовый образец «проверить объём за минуту»: простая картинка и математически
верная карта нормалей к ней. Ничего не нарисовано «на глаз» — нормаль каждой
видимой грани получена поворотом куба, поэтому любая ошибка рендера видна сразу.

| Файл | Что это |
|---|---|
| `cube.png` | картинка кубика 512×512, фон прозрачный |
| `cube-normal.png` | карта нормалей к ней, та же сетка |
| `cube-debug.png` | лист 2×2: картинка, ожидаемый свет сверху, свет слева, так выглядит DirectX-карта |

## Конвенция карты

**OpenGL: зелёный канал смотрит вверх** (+Y вверх). Красный — вправо, синий — на
зрителя. Так карту отдают Blender, Substance Painter и большинство
генераторов; именно так её читает рендер (`src/render/lighting.ts`:
`vec2 xy = vec2(texel.x, -texel.y)` — перевод «вверх» в координаты холста, где Y
растёт вниз).

Порог арифметики карты: у единичной нормали максимум компоненты не меньше
`1/√3 ≈ 0.577`, после кодирования `(n + 1) / 2` **любая настоящая нормаль ярче
0.79**. Поэтому тёмный и прозрачный тексель считается «здесь пусто»: объёма нет,
соседние карты такая зона не перекрывает.

Нормали видимых граней (после поворота куба):

| Грань | Нормаль | В карте (RGB) |
|---|---|---|
| верх | `(0, 0.816, 0.577)` | `(0.50, 0.91, 0.79)` — мятный |
| левая | `(−0.707, −0.408, 0.577)` | `(0.15, 0.30, 0.79)` — синий |
| правая | `(0.707, −0.408, 0.577)` | `(0.85, 0.30, 0.79)` — розовый |

## Как проверить в редакторе

1. Импортируйте `cube.png` — появится спрайт в центре сцены.
2. Выберите его, вкладка **«Параметры»** → «Карта нормалей» → выберите
   `cube-normal.png`, «Сила» — 100 %.
3. Поставьте свет выше кубика (объект «Свет», круг или экран).

Что должно быть: верхняя грань светлеет, обе боковые темнеют, граница между
гранями остаётся резкой, ребра не «светятся». Объём должен стоять на кубе при
любом сдвиге и масштабе камеры.

Если верхняя грань **темнеет**, а боковые светлеют — карта читается как
DirectX (зелёный вниз), то есть её надо собрать в OpenGL. Панель 4 на
`cube-debug.png` показывает ровно этот случай.

## Пересборка

```
npm run example:normals
```

Генератор — `scripts/make-normal-example.mjs`: считает проекцию и нормали сам,
PNG пишет через `node:zlib`, без зависимостей. Тест
`tests/e2e/normal-example.spec.ts` читает готовые PNG и сверяет их с
математикой — если пример разойдётся с рендером, тест упадёт.
